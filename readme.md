# 手把手教你发行自己的加密货币-ETH
## 关键字：ETH,加密货币,发行,智能合约

## 本教程准备：
1、会魔法上网（科学上网 爬梯子），这里不懂的话建议直接关闭本教程。（必须）
2、需要一个以太坊钱包，这里推荐MetaMask。（必须）
